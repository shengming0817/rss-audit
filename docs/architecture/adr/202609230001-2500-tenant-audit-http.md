# #2500 租户内审计 HTTP

状态：采纳；补充 #2495/#2497，不改变 V1 持久化格式或数据库 schema。

唯一 HTTP owner 为 rss-audit-http-axum，唯一当前合同为 GET /api/v2/audit/entries。
DTO、游标与错误映射由 adapter 私有代码持有，合同与宿主接入见
[crate README](../../../crates/audit-http-axum/README.md)。旧 Web DTO 不成为真源，
没有旧路由、兼容 decoder、alias、管理池或跨租户入口。Web 迁移由其 owner 独立持有。

宿主按请求认证并注入 Arc<S>；必选 AuditQueryPolicy 校验有效性并授权。泛型证据和 grant
不证明任意宿主真实认证过；该信任边界明确归宿主。client navigation 不提供租户权限。
一次消费锁不能证明身份新鲜度，因此直接使用 Axum 原生请求扩展，不增加会话状态机。

普通分页在首屏 SQL snapshot 内固定 head 上界，续页只在原范围内前进，最后页无 nextCursor。
这避免每页新增查询审计造成 limit=1 永不结束。所有普通读取共用同一 SQL；未承诺的
Cursor::after 由 Cursor::resume 替换，无双路径。固定上界不是跨请求 MVCC snapshot、
完整性证明或外部 checkpoint；范围内缺口仍 fail-closed。摘要明确未验证密码学完整性。

产品显式选择是否必须审计查询；Required 的 prepared bytes 由宿主持久保存，组件无法以
类型证明保存已发生。查询和追加在同一租户事务，只有 COMMIT ACK 后返回摘要。审计语义
是查询尝试，不声称 HTTP 客户端已收到响应。不新增恢复队列或自动重试平台。

正常 await 保留 provider 的全部结算分类。预算耗尽不刷新 deadline；直接丢弃 handler 时
连接退役，但没有可交付 response extension，unknown 恢复依赖宿主原始持久意图。
对外只返回闭合安全错误，内部诊断不成为新的 commit evidence。

T1 固定参数/游标/摘要/错误边界，T2 复用真实 PostgreSQL launcher 与现有 HTTP suite，覆盖普通
查询及必需查询审计。真实宿主接入、认证、TLS 部署和生产 T3 由消费产品验证；
日常选择遵循[验证范围](../../rules/verification-scope.md)。
